# 手动终端指引

交付需要用户亲自在本机终端运行的实际命令时，给出打开终端的方法、应使用的工作目录（该步骤有要求时）、一段可复制的命令和预期结果。填入本次已确认的参数和实际路径。助手自行执行的命令、文档示例和贴给旧聊天的提示词各按原流程处理。旧聊天探针须继承选定原会话的默认工作目录。

## 打开终端并粘贴

只展示执行命令的电脑对应的一张图。从本次加载的 `SKILL.md` 所在目录解析对应资产，使用实际绝对路径附图。图示用于定位窗口和提示符，命令始终以文本代码块提供。无论图片能否显示，都用用户的语言给出以下对应系统的文字步骤。宿主只能显示文字且图文件存在时，给出图片的完整本机路径。Windows 可把路径贴进资源管理器地址栏后按回车。macOS 可在访达按 `⌘ + Shift + G`，输入图片所在文件夹，打开对应 PNG。图文件缺失时直接给文字步骤。

| 系统 | 文字步骤 | 图示 |
|---|---|---|
| Windows | 按 `Windows 徽标键 + R` 打开「运行」，启动通过预检的 Windows PowerShell 5.1 或 PowerShell 7。助手应给出已核实可用的命令 `powershell.exe`、`pwsh.exe` 或对应的完整路径。打开独立窗口后，把命令粘贴到 `PS …>` 提示符后，再按 `Enter`。 | [打开 PowerShell](../assets/open-terminal-windows.png) |
| macOS | 按 `⌘ + 空格` 打开「聚焦」，搜索 `Terminal`（终端），选中终端应用后按 `Return`。在新打开的终端窗口中，把命令粘贴到提示符后，再按 `Return`。 | [打开终端](../assets/open-terminal-macos.png) |

## 离线切换

单目录取 `cutover.py prepare` 输出的最后一行命令。批次解析 `project_batch.py prepare` 输出的 JSON，只取解码后的 `command` 字段值。在用户退出前交付所选模式生成的那一段命令，保留原有引号和参数，并附对应系统的图示。提醒用户先保存工作，把命令和运行记录的位置记在项目目录之外，再退出所有占用项目的应用、Agent 和终端。Windows 桌面应用还需退出托盘后台。用上面的系统入口打开独立终端，保持它在待迁项目之外。

- **A 我手动改名。** 退出占用程序后，在资源管理器或访达把计划中仍待改名的原件改为指定的同级备份名，再在项目树外打开独立终端，粘贴并执行命令。
- **B 让命令帮我改名。** 退出占用程序后，在项目树外打开独立终端，粘贴并执行命令，由命令完成待处理的改名和链接。

根据本次计划说明预期的旧入口、目标和备份。执行后重开 Agent，反馈结果，再按原流程核验实际链接和目录身份。重试前先核对哪些动作已完成。
